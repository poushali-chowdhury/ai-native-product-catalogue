# Time spent

| Activity | Time |
| --- | --- |
| Planning | 1.5 hour |
| Building | 4 hours |
| Testing | 3 hours |
| Reviewing | 1.5 hour |
| **Total** | **10 hours** |

Planning was the stack choice, the provider boundaries, and how a reviewer would run the app.

Building was done with Cursor: the React client, the Node API, the enquiry email, Docker Compose, and the submission notes.

Testing took longer than expected. It covered the backend and frontend test suites, the 10 end-to-end tests, a manual pass through the catalogue as a customer, and checking the sales email in Mailpit.

Reviewing was checking the generated code and correcting it. That included the frontend scaffold, the React Router and jsdom versions, the local Mailpit address, the missing frontend and backend services in Compose, and the end-to-end host names.
